Mathematics is the language of the nature!¶

Algebra is the language of mathematics.

A group is a set with a binary operation that is associative, every element has an inverse and there exist an identity element. A group with an operation that is commutative is called an abelian group.

A ring is a set with two binary operations usually denoted as (+) and (.). such that with respect to (+) it is an abelian group and (.) is associative.
